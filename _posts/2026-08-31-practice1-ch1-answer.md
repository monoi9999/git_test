이 글은 [실습1 성적데이터 집계하기](/2026/08/31/practice1-ch1/) 문제에 대한 답안예시입니다. 먼저 직접 프롬프트를 작성해서 시도해본 뒤, 이 글과 비교해보시길 권합니다.

## [모범 프롬프트 예시]

문제의 [요구사항]과 [주의사항]을 모두 반영해서, 한 번의 프롬프트로 요청하면 아래와 같습니다.

> "첨부한 성적 데이터에서(배경), ID별로 국어·영어·수학 점수의 총점과 평균을 계산해줘. 평균은 소수 첫째 자리까지만 표시해줘(요청 1). 평균을 기준으로 학점을 매겨줘. 기준은 90점 이상 A, 80점 이상 B, 70점 이상 C, 60점 이상 D, 60점 미만은 F야(요청 2). 총점을 기준으로 전체 순위를 매겨줘. 동점자는 같은 순위로 처리하고, 그다음 순위는 동점자 수만큼 건너뛰어줘(요청 3). 결과를 순위 오름차순으로 정렬한 표로 보여주고, ID·과목별 점수·총점·평균·학점·순위가 모두 포함된 엑셀 파일로 만들어서 다운로드 링크를 줘(형식)."

## [프롬프트 해설]

문제의 각 조건이 프롬프트의 어느 부분에 대응하는지 짚어보면 다음과 같습니다.

| 문제의 조건 | 프롬프트에 반영한 부분 |
|---|---|
| 총점·평균 계산 (요구사항) | "총점과 평균을 계산해줘" |
| 평균 소수 첫째 자리까지 (주의사항) | "평균은 소수 첫째 자리까지만 표시해줘" |
| 학점 기준 90/80/70/60 (주의사항) | "기준은 90점 이상 A..." 로 숫자를 직접 명시 |
| 동점자 처리 규칙 (주의사항) | "동점자는 같은 순위로 처리하고, 그다음 순위는 건너뛰어줘" |
| 엑셀 파일로 저장 (요구사항) | "엑셀 파일로 만들어서 다운로드 링크를 줘" |

기준이 되는 숫자와 규칙을 문장으로 설명하지 않고 **정확한 수치와 절차로 못박은 것**이 핵심입니다. "적당히 학점 매겨줘"처럼 애매하게 요청하면, AI가 임의로 기준을 정해버릴 수 있습니다.

## [자주 하는 실수와 주의사항]

### A. 프롬프트 작성 실수

- 학점 기준을 안 알려줘서 AI가 임의 기준(예: 85점 이상 A)으로 매기는 경우
- 동점자 처리 규칙을 안 줘서 순위가 11, 12로 이어지거나(건너뛰지 않음) 반대로 순위가 꼬이는 경우
- 평균 소수점 자리수를 안 정해줘서 87.666...처럼 지저분하게 나오는 경우
- 데이터가 많을 때 AI가 합계를 실제로 틀리게 계산하는 경우 (검산하지 않으면 놓치기 쉬움)

### B. 기술적 에러 상황

- **파일 업로드 실패**: CSV가 인식되지 않거나 "파일을 읽을 수 없습니다" 오류가 뜨는 경우 → 파일 이름에 특수문자가 없는지, 파일이 제대로 저장됐는지 확인
- **한글 인코딩 깨짐**: 국어·영어·수학 헤더나 값이 깨져 보이는 경우 → CSV를 UTF-8로 저장했는지 확인 (엑셀 기본 저장 방식은 다르게 깨질 수 있음)
- **무료 버전 사용량 제한**: 파일 분석 기능을 반복 사용하다 "사용량을 초과했습니다" 메시지가 뜨는 경우 → 일정 시간 후 재시도
- **다운로드 링크 만료·오류**: 엑셀 파일 링크가 안 열리거나 만료된 경우 → "파일을 다시 만들어줘"라고 재요청
- **파일을 실제로 안 만들고 코드나 설명만 보여주는 경우**: → "다운로드 가능한 실제 파일로 만들어서 링크를 줘"라고 더 명확히 재요청
- **응답이 중간에 끊기는 경우**: 표가 다 안 나오고 잘리는 경우 → "이어서 계속해줘"라고 요청

## [결과 검증 방법]

받은 결과를 그대로 믿지 말고, 아래를 직접 확인해보세요.

- ID 1~2개를 골라 국어+영어+수학을 직접 더해서 총점이 맞는지 검산
- 평균 90점, 80점처럼 **학점 경계값에 걸리는 사람**의 등급이 올바르게 매겨졌는지 확인
- 동점자(`user_310mn`, `user_a03`)가 정말 같은 순위로 나왔는지, 그다음 순위가 제대로 건너뛰었는지 확인
- 최종 엑셀 파일을 열어서 20명 전부 빠짐없이 들어있는지 확인

## [비교: 부족한 프롬프트 vs 모범 프롬프트]

> ❌ "이 데이터 집계해서 학점이랑 순위 매겨줘"

기준이 하나도 없어서, AI가 학점 기준과 동점자 처리 방식을 마음대로 정해버립니다. 같은 질문을 다시 해도 기준이 달라질 수 있습니다.

> ✅ 위 [모범 프롬프트 예시]처럼 학점 기준, 동점자 규칙, 소수점 자리수, 최종 저장 형식까지 전부 숫자와 절차로 명시

기준이 명확하니 몇 번을 다시 요청해도 같은 결과가 나오고, 검증하기도 쉬워집니다.

## [최종 체크리스트]

| 항목 | 확인 |
|---|---|
| 총점이 정확히 계산됐는가 | ☐ |
| 평균이 소수 첫째 자리까지 표시됐는가 | ☐ |
| 학점이 지정한 기준(90/80/70/60)대로 매겨졌는가 | ☐ |
| 동점자가 같은 순위로 처리되고, 다음 순위가 건너뛰었는가 | ☐ |
| 순위 기준으로 정렬됐는가 | ☐ |
| 결과가 엑셀 파일로 저장되어 다운로드됐는가 | ☐ |

## [참고: AI가 사용한 파이썬 코드]

ChatGPT의 파일 분석 기능은 실제로는 파이썬 코드를 실행해서 결과를 만듭니다. 참고로, 이 문제를 풀 때 AI가 내부적으로 사용했을 법한 코드는 아래와 같습니다 (직접 실행할 필요는 없지만, "AI가 어떤 방식으로 계산했는지" 궁금하신 분을 위한 참고 자료입니다).

```python
import pandas as pd

# 입력 CSV 읽기
df = pd.read_csv("practice1-input.csv")

# 총점, 평균 계산
df["총점"] = df["국어"] + df["영어"] + df["수학"]
df["평균"] = (df["총점"] / 3).round(1)

# 학점 매기기
def get_grade(avg):
    if avg >= 90:
        return "A"
    elif avg >= 80:
        return "B"
    elif avg >= 70:
        return "C"
    elif avg >= 60:
        return "D"
    else:
        return "F"

df["학점"] = df["평균"].apply(get_grade)

# 순위 매기기 (동점자는 같은 순위, 다음 순위는 건너뜀)
df["순위"] = df["총점"].rank(method="min", ascending=False).astype(int)

# 순위 기준으로 정렬
df = df.sort_values("순위").reset_index(drop=True)

# 엑셀 파일로 저장
df.to_excel("practice1-output.xlsx", index=False)
```

`rank(method="min", ascending=False)`가 바로 "동점자는 같은 순위, 다음 순위는 동점자 수만큼 건너뛰기" 규칙을 그대로 처리해주는 부분입니다. 프롬프트로 말로 설명했던 규칙이 실제로는 이렇게 코드 한 줄로 구현된다는 것을 알아두면, 나중에 더 복잡한 요청을 할 때도 도움이 됩니다.
